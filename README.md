# HR Dashboard Analysis

## Project Overview
This project is an HR Dashboard created using Power BI to analyze employee data and attrition trends.

## Features
- Overall employee analysis
- Attrition count and attrition rate
- Department-wise attrition analysis
- Age group analysis
- Gender-based attrition analysis
- Job role analysis
- Education field-wise attrition

## Tools Used
- Power BI
- Excel / CSV Dataset

## Dashboard Insights
- Total Employees: 1470
- Attrition Count: 237
- Attrition Rate: 16.12%
- Active Employees: 1233
- Average Age: 36.92

## Project Purpose
The purpose of this dashboard is to help HR teams understand employee attrition patterns and make data-driven decisions.
